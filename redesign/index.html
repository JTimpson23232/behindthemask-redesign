Behind the Mask · Six Concepts for the Redesign

Six rooms for the work
to live in.

Same artist. Same gallery. Six completely different doors to walk through.

Every concept is engineered around one rule: the site should feel like hospitality, not exhibition. None opens with shock imagery. None asks the visitor to explain herself at the door. Each solves "safe" a different way.

The brief: real, emotionally safe, creative and artistic. Someone survived something here. Not "look how tortured I was." Each concept ships with a printable PDF you can share with Priscilla.

How to choose, without overthinking it.

Open each one. Scroll the whole homepage. Don't read the placeholder copy too closely. Notice which room makes your shoulders drop.

Hearth if you want a friend's living room. Garden if healing should have its own pace. Lantern if you want the site to refuse peppy. Letter if you want it intimate and direct. Atelier if the work should be treated like the art it is. Threshold if you want it dreamlike and soft.

All six refuse the "look how tortured I was" energy. Each gets there a different way. Tell us which room feels like yours and we build it out fully.
